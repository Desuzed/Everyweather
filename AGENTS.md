# Everyweather

- Android app: Kotlin, Compose, Koin, Flow, Room, DataStore, Retrofit; one `app` module. Keep changes small and preserve existing behaviour and user data. Do not introduce KMP, a new DI framework or broad modularisation without a concrete requirement.
- Read `git status` first; preserve existing staged and unstaged work. Never commit/push unless requested. `AGENTS.md` and `.codex` agent configuration may be included when explicitly requested. Keep `docs/PROJECT_AUDIT_2026-09-09.md` local: never stage or commit it.
- Delegate independent routine work (inventory, mechanical edits, test cases following an established pattern, documentation) to **gpt-5.6-luna**. Use **gpt-5.6-terra** for bounded refactoring with an agreed algorithm and moderate reasoning. The primary agent owns ambiguous design, races/migrations, integration and review. Explicitly select the model; don't silently substitute one.
- Give each subagent a bounded task, exclusive file ownership and expected verification. No concurrent edits to the same files. One coordinator runs Gradle/emulator checks; review all delegated diffs before completion.
- Use `./scripts/android.sh doctor`, `check`, `devices`, `ui`; see `docs/DEVELOPMENT.md`. Prefer Gradle wrapper, adb, emulator and SDK command-line tools to IDE clicking. Select the target device explicitly when ambiguous. Never wipe a device to make tests pass.
- Before fixing a bug, add a failing regression test. Use JVM tests for pure logic/ViewModels, integration tests for storage/network contracts, Compose tests for user flows. Use fakes, fixed time and test dispatchers; no production network/analytics in automated tests. Keep `docs/FUNCTIONAL_TEST_MATRIX.md` truthful about coverage and unverified scenarios.
- Validate relevant tests, then `assembleDebug testDebugUnitTest lintDebug`; run UI checks for changed interaction flows. Report executed commands/results and remaining gaps. Do not suppress failing tests or blanket-baseline lint. Generated-code warnings require build-configuration fixes.
- UI state flows down, actions flow up. Keep platform calls in adapters/routes; preserve coroutine cancellation, cancel superseded requests, and test lifecycle/process restoration. One modal host per sheet/dialog. Preserve RU/EN, theme choice, accessibility and system/IME insets.
- Dependencies belong in the version catalog; update compatible groups with validation. Debug/CI must build without release credentials. Never print/commit API keys, signing files or local.properties. Keep release signing/upload separate from validation; do not publish or bump versions as a side effect of checks.
